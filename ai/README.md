# Speech Practice

An AI-powered public speaking coach that provides real-time feedback on your speech delivery. Practice presentations with live metrics, teleprompter support, and post-session AI coaching — all running locally on your machine.

## Features

### Real-Time Feedback
- **Speech Metrics** — Live words-per-minute, volume level, and pitch tracking with color-coded status indicators
- **Filler Word Detection** — Counts "um", "uh", "like", "basically", and 13 other filler words as you speak
- **Facial Expression Analysis** — Detects happy, surprised, angry, and neutral expressions using MediaPipe face landmarks
- **Eye Contact Tracking** — Monitors whether you're looking at the camera
- **Posture & Gesture Analysis** — Evaluates uprightness, shoulder alignment, and gesture openness via pose estimation
- **Live Overlay** — All metrics rendered as a heads-up display on your camera feed

### Teleprompter
- **Script Loading** — Save, load, and manage speech scripts
- **Real-Time Position Tracking** — Highlights your current position in the script using fuzzy word matching against live transcription
- **Mispronunciation Detection** — Marks words with low recognition confidence with red underlines
- **AI Script Generation** — Generate practice speeches on any topic for a specified duration using Ollama

### Post-Session Analysis
- **Performance Scores** — 0-100 scores across 5 dimensions: Pace, Clarity, Expression, Posture, and Overall
- **Charts** — WPM over time, filler word breakdown, volume dynamics, and expression timeline
- **AI Coaching Feedback** — Detailed strengths, areas for improvement, and exercises generated by Ollama (llama3)
- **Visual Feedback** — Body language analysis from sampled video frames using a vision model (llava)
- **Session History** — Browse and compare past practice sessions

### Privacy-First
- All processing runs locally — Vosk for transcription, MediaPipe for vision, Ollama for AI feedback
- No data leaves your machine

## Prerequisites

- **Python 3.10+**
- **Webcam** and **Microphone**
- **[Ollama](https://ollama.com/)** (optional, for AI feedback and script generation)
  - Pull the required models:
    ```bash
    ollama pull llama3
    ollama pull llava
    ```

## Quick Start

The easiest way to run the application:

```bash
python run.py
```

This will automatically:
1. Create a Python virtual environment
2. Install all dependencies
3. Launch the Gradio web UI

Alternatively, set up manually:

```bash
python -m venv venv
source venv/bin/activate        # Linux/macOS
# venv\Scripts\activate         # Windows
pip install -r requirements.txt
python app.py
```

The app opens at `http://localhost:7860` in your browser.

## Usage

### Practice a Speech

1. Open the **Practice** tab
2. (Optional) Paste or load a script in the teleprompter panel
3. Click **Start Session** — your camera and microphone activate
4. Speak naturally while watching the real-time feedback overlay
5. Click **Stop Session** when done
6. Switch to the **Report** tab to see your scores, charts, and AI feedback

### Manage Scripts

1. Open the **Scripts** tab
2. Type a script name and content, then click **Save**
3. Or use the **AI Script Generator** — enter a topic and duration to auto-generate a speech

### Review History

1. Open the **History** tab
2. Click **Refresh** to load past sessions
3. Select a session to view its report

## Configuration

Key settings can be adjusted in `config.py`:

| Setting | Default | Description |
|---------|---------|-------------|
| `TARGET_WPM_LOW` / `HIGH` | 120 / 160 | Ideal words-per-minute range |
| `TIMER_INTERVAL` | 0.15s | UI refresh rate |
| `CAMERA_WIDTH` / `HEIGHT` | 640 / 480 | Camera resolution |
| `SAMPLE_RATE` | 16000 Hz | Audio sample rate |
| `OLLAMA_MODEL` | llama3 | Text model for AI feedback |
| `OLLAMA_VISION_MODEL` | llava | Vision model for visual feedback |
| `FRAME_SAMPLE_INTERVAL` | 30s | Interval between video frame samples |
| `MAX_SAMPLE_FRAMES` | 6 | Max frames sent to vision model |
